최근 학습 기록

역사 흐름

세부 사실을 외우기 전에 시대적 배경과 사건의 연결 관계를 파악하세요.

1914~1918 · 제1차 세계 대전

전쟁 이후 민족 자결주의가 알려졌지만, 식민지 민족에게 일관되게 적용된 것은 아니었습니다.

1910년대 · 무단 통치와 독립운동 기지 건설

헌병 경찰 중심의 통치, 조선 태형령(1912), 토지 조사 사업. 국외에서는 서간도·북간도·연해주·미주 등지에서 독립운동 기반을 마련했습니다.

1919 · 3·1 운동과 대한민국 임시정부

3·1 운동이 전국적으로 확산했고, 상하이에서 대한민국 임시정부가 수립되었습니다.

1920년대 초 · 무장 독립전쟁과 탄압

봉오동 전투와 청산리 대첩 이후 일본군의 간도 지역 탄압이 이어졌습니다. 독립군은 밀산 이동과 자유시 참변 등을 겪으며 재편되었습니다.

1920년대 · 문화 통치와 실력 양성·사회 운동

산미 증식 계획, 회사령 철폐, 민립 대학 설립 운동, 물산 장려 운동, 6·10 만세 운동, 광주 학생 항일 운동 등이 전개되었습니다.

1920년대 후반~1930년대 · 통합과 무장 투쟁

참의부·정의부·신민부, 민족 유일당 운동, 국민부와 혁신의회 등 조직 재편이 이루어졌습니다. 한중 연합 작전과 한인애국단 활동도 이어졌습니다.

1930년대 후반~1940년대 · 전시 동원과 독립운동

민족 말살 정책과 강제 동원이 강화되었습니다. 한국광복군 창설, 조선의용대 활동, 조선건국동맹 결성 등이 해방을 준비하는 움직임으로 이어졌습니다.

1945 · 광복과 분단의 전개

광복 이후 미·소 군정이 들어섰고, 모스크바 3국 외상 회의, 미소 공동 위원회, 좌우 합작 운동 등을 둘러싸고 정치적 갈등이 이어졌습니다.

1948 · 남북한 정부 수립

남한에서는 5·10 총선거와 대한민국 정부 수립이 이루어졌고, 북한에서는 조선민주주의인민공화국이 수립되었습니다. 제주 4·3 사건은 해방 이후 정부 수립 과정의 갈등과 국가 폭력을 이해하는 중요한 사건입니다.

심화 학습

기본 흐름에서 비중이 작았던 단체와 사건을 시대·지역별로 보충합니다. 항목을 눌러 핵심 설명을 확인하세요.

문제 풀이

일반 문제를 푸는 공간입니다. 복습 문제는 별도의 '오답·복습 전용' 메뉴에서 풉니다.

문제 묶음 선택

새 문제 묶음은 기존 기록에 추가됩니다. 생성된 묶음은 문제 풀이를 끝내거나 페이지를 이동해도 기록에서 다시 확인할 수 있습니다.

오답·복습 전용 공간

이 공간은 일반 문제 풀이와 분리되어 있습니다. 저장된 문제를 다시 풀어도 원래의 풀이 기록은 변경되지 않습니다.

복습할 기록 선택

학습 기록

문제·선택지·내 답·정답·해설이 저장됩니다. 복습은 기록을 수정하지 않고 별도 풀이로 처리합니다.

불러오기는 기존 기록을 기본적으로 보존하고, 새 데이터만 추가합니다.

문제 생성 방식

이 사이트의 기본 생성 기능은 내장된 문제 자료를 조합하여 새로운 문제 묶음을 만듭니다. 외부 AI API 없이도 여러 번 생성할 수 있습니다.

질문과 선택지가 완전히 새로운 역사 사실을 자동 검증하는 외부 AI 생성 기능은 기본 포함하지 않았습니다. 정확성을 확인하지 않은 문제를 사실처럼 저장하지 않기 위해서입니다.
