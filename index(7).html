학습기록 기능

퀴즈를 완료하면 문제와 선지, 선택한 답, 정답, 해설이 함께 저장된다. 기록 메뉴에서 과거 문제를 펼쳐 보고 틀린 문제만 다시 풀 수 있다.

기록은 현재 브라우저에 저장된다. 브라우저 데이터 삭제나 다른 기기 사용 시 사라질 수 있으므로 설정 메뉴에서 백업 파일을 내려받을 수 있다.

퀴즈 설정

범위·문제 수·난이도를 선택하세요. 각 문제는 선지 5개로 구성됩니다. 난이도는 기존 문제은행의 개념 연결·사료 해석·사실 확인 수준을 기준으로 분류합니다. 선택한 범위·난이도에 있는 문제만 중복 없이 출제되며, 해당 난이도 문제가 없으면 그 범위의 전체 문제에서 출제됩니다.

학습기록·오답복습

과거에 푼 문제의 실제 내용과 해설을 확인한다. 기록을 열면 모든 문항을 개별적으로 펼쳐 볼 수 있다.

각 기록의 문제와 해설 보기를 누르면 질문, 5개 선지, 내가 고른 답, 정답, 해설, 참고 정보를 확인할 수 있다.

사료·사진 자료

공개된 역사 사진을 검색하고, 신뢰할 수 있는 역사 자료 기관에서 원문 사료를 찾아볼 수 있다.

사진은 Wikimedia Commons의 공개 검색 결과를 불러온다. 사진마다 저작자·이용 허가 조건이 다를 수 있으므로, 사용 전 원본 설명 페이지에서 출처와 라이선스를 확인하자. 검색 기능은 인터넷 연결이 필요하다.

AI 문제 생성 (선택 사항)

Cloudflare Worker 등의 서버 URL을 입력하면 서버가 지원하는 경우 AI 문제 생성을 시도한다. URL을 비워 두어도 기본 문제은행은 정상 작동한다.

API 키를 HTML이나 공개 저장소에 직접 넣지 마세요. 비밀 키는 서버 환경변수에 보관해야 합니다. 이 페이지의 AI 연동은 호환되는 Worker가 별도로 구현되어 있을 때만 작동합니다.
