세계 정세

한국사와 세계사 연결

세계 대전, 러시아 혁명, 대공황, 제2차 세계 대전이 한국사와 같은 시간대에 어떻게 진행되었는지 비교한다.

학습 순서 추천

  1. 연표에서 시대의 큰 흐름을 확인한다.
  2. 심화 자료에서 지역·단체·정책을 구체적으로 학습한다.
  3. 학습 카드로 인물과 단체의 특징을 회상한다.
  4. 문제를 풀고, 오답·복습 화면에서 해설을 확인한다.

학습 기록은 현재 사용하는 브라우저의 저장 공간에 보관된다. 브라우저 데이터 삭제나 다른 기기 사용 시 기록이 사라질 수 있으므로 JSON 백업 기능을 이용할 수 있다.

독립운동·한국사 세계 정세 식민 통치 정책

학습 카드

카드의 설명을 읽고, 단체의 이름이나 특징을 가리고 스스로 떠올려 보자.

문제 풀기

심화 자료와 세계 정세를 바탕으로 문제를 새로 구성한다. 새 세트를 만들어도 이전 기록은 삭제되지 않는다.

문제 세트는 생성할 때마다 별도 저장된다. 출제 가능한 항목 수보다 문제 수가 많으면 가능한 만큼 출제한다.

위의 버튼을 눌러 문제 세트를 만들어 보자.

오답·복습

문제 풀이 화면과 분리된 복습 공간이다. 과거에 푼 세트를 다시 풀어도 기존 기록은 유지된다.

학습 기록

새 문제 세트와 풀이 결과를 누적해서 저장한다. 이 화면에서는 기록을 자동으로 삭제하지 않는다.

백업을 불러올 때는 기존 기록을 덮어쓰지 않고 새 항목으로 추가한다.

참고 자료와 용어 주의

세부 연도나 단체의 계승 관계는 자료마다 서술 방식에 차이가 있을 수 있다. 수행평가에서는 교과서와 수업 자료를 우선 확인하자.

한국사 자료

  • 국사편찬위원회 한국사 데이터베이스 — 한국사 사료와 연구 자료
  • 우리역사넷 — 시대별 한국사 해설
  • 국가기록원: 3·1운동 관련 독립선언서류 — 국내외 독립운동 관련 자료
  • 한국민족문화대백과사전 — 단체·인물·사건 항목

이 사이트의 용어 사용

  • 3부: 만주 지역의 참의부·정의부·신민부를 가리킨다. 각 부는 군사 활동과 한인 사회의 자치 행정을 함께 추진했다.
  • 조선태형령: 1912년에 제정된 식민 통치기의 태형 관련 법령이다. 1920년에 폐지되었다.
  • 조선건국동맹: 1944년 여운형 등이 조직한 국내 비밀결사로, 광복 이후 건국 준비 활동과 연결된다.
  • 제주 4·3: 1947년부터 1954년까지 이어진 사건이다. 1948년 정부 수립과 시간적으로 겹치므로, 단일 연도 사건으로 축약하지 않는다.
  • 세계 정세: 한국사와 같은 시기에 진행된 사건을 비교하기 위한 자료다. 세계 사건이 한국 독립운동에 미친 영향은 구체적 경로를 구분해서 살펴야 한다.
이 학습 자료는 고등학교 한국사 학습을 위한 요약 자료다. 모든 세부 사항을 완전하게 다루지는 않으며, 정확한 서술은 교과서와 공신력 있는 사료를 함께 확인해야 한다.
